# 👋 안녕하세요, 꾸준히 배우고 성장하는 개발자 한진형입니다.

> **"기본에 충실하며, 소통과 배움을 통해 팀과 함께 성장하겠습니다."**

- 정해진 일정과 협업 방식을 존중하며, 일정 준수와 원활한 팀 소통을 최우선으로 생각합니다.
- 새로운 기술을 배우는 데 주저함이 없으며, 프로젝트 과정에서 마주치는 문제를 하나씩 해결해 나가는 과정에서 즐거움을 느낍니다.
- **Spring Boot 기반 백엔드**와 **React 기반 프론트엔드**를 모두 아우르며, 데이터가 생성되어 화면에 노출되기까지의 전체 개발 흐름을 이해하고 구현할 수 있습니다.
